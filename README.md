## Como instalar no Windows

1. Baixe o zip acima.
2. Clique com o botão direito no arquivo → **Extrair tudo…**
3. Abra a pasta **Simulador Parapente Brasil** e dê dois cliques em **Simulador Parapente Brasil.exe**.

Não precisa instalar nada. Se o Windows mostrar *"O Windows protegeu o computador"*, clique em **Mais informações → Executar assim mesmo**
(o aviso aparece em todo programa novo que ainda não tem muitos downloads).

**Precisa de:** Windows 10 ou 11 (64 bits). A câmera é opcional — sem ela, você voa pelo teclado.

## Como instalar no Mac

1. Baixe o zip do Mac (o Safari já abre o zip sozinho; senão, dê dois cliques nele).
2. Arraste **Simulador Parapente Brasil** para a pasta **Aplicativos**.
3. Abra o app. Na primeira vez, o Mac pergunta se ele pode usar a **câmera**: aperte **Permitir** (é ela que lê a sua
   cabeça e as suas mãos). O **microfone** só é pedido se você usar o rádio (tecla T).

O app é assinado e verificado pela Apple. Se você negou a câmera sem querer: **Ajustes do Sistema → Privacidade e
Segurança → Câmera** → ligue o Simulador Parapente Brasil.

**Precisa de:** macOS 12 ou mais novo.

## Como pilotar

| Com a câmera | O que acontece |
|---|---|
| Vire a cabeça | a vista do piloto acompanha |
| Mãos no alto / uma mão no peito | batoques soltos / curva para aquele lado |
| Mão aberta | o batoque fica parado (para usar o teclado) |
| Cabeça deitada para um lado | peso do corpo daquele lado |
| Passo atrás → virar o corpo → vir para a frente | decolagem invertida: puxar, girar e correr |

| Teclado | |
|---|---|
| ← / → | batoques (Shift: até o fundo) |
| ↓ | os dois batoques no fundo (flare) |
| Espaço | no chão, o passo; no ar, o acelerador |
| Q / E | peso do corpo |
| V | troca a vista |

A imagem da câmera é usada só no seu computador: nada é gravado nem enviado.
